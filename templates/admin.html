API Configuration

Set your marketplace API credentials in .env (see setup.md for instructions).

eBay API

eBay Developer Portal → Create an app, then set: 

EBAY_CLIENT_ID=your_client_id
EBAY_CLIENT_SECRET=your_client_secret

Etsy API

Etsy Developer Portal → Create a Seller App, then set: 

ETSY_API_KEY=your_keystring
ETSY_API_SECRET=your_shared_secret

Google Sign-In

Sign in to this dashboard with a Google account. Create the OAuth client at Google Cloud Console →

  1. In Google Cloud Console, pick (or create) a project.
  2. Under APIs & Services → OAuth consent screen: set an app name and your support email. Status “Testing” is fine for personal use.
  3. Under APIs & Services → Credentials → Create credentials → OAuth client ID, choose Web application, leave the JS origins empty, and add the redirect URI shown below.
  4. Copy the Client ID and Client Secret into the fields below, then save.

Teams

Teams share one inventory. Everyone you add here (by email) can sign in — with Google — and see the same listings. New sign-ins join the Default Team automatically, so sharing works out of the box.
