Google Sign-In

Sign in to this dashboard with a Google account. Create the OAuth client at Google Cloud Console →

  1. In Google Cloud Console, pick (or create) a project.
  2. Under APIs & Services → OAuth consent screen: set an app name and your support email. Status “Testing” is fine for personal use.
  3. Under APIs & Services → Credentials → Create credentials → OAuth client ID, choose Web application, leave the JS origins empty, and add the redirect URI shown below.
  4. Copy the Client ID and Client Secret into the fields below, then save.
